# SNAPx Design System

Web components and design tokens for SNAPx, published as
`@select-networx/snapx-ds` and used by snapx-admin. Everything is styled from
the approved SNAPX redesign prototype, in two looks: **Select** (orange, the
default) and **SNAPX** (blue). Use the switch in the top bar to see these docs
in either.

The library is at an early stage. It has the tokens and the foundational
components: buttons, text fields, search, headings, body text and labels.
Cards, badges, tables, dialogs and the rest come later.

## Where to start

- **[Using the package](/install):** install it in an app, load it, and work
  with the components from markup and JavaScript.
- **[Choosing components](/choosing-components):** which component to use for
  each part of a screen, with the prototype's common patterns.
- **[Design tokens](/tokens/design-tokens):** colours, type, spacing and the
  rest, for anything you style yourself.
- **[Prototype gaps](/prototype-gaps):** what the prototype doesn't cover yet,
  and the decisions made so far.

Before building something new, read the [design principles](/design-principles)
and [accessibility](/accessibility) guidance.
