
## Color

Use these colors only:

### Actions

```css
--action-primary-foreground: white;
--action-primary-background: blue;
--action-primary-border: 1px solid blue;
--action-secondary-foreground: white;
--action-secondary-background: blue;
--action-secondary-border: 1px solid blue;
--action-auxiliary-foreground: white;
--action-auxiliary-background: blue;
--action-auxiliary-border: 1px solid blue;
```

### Controls

```css
--control-primary-foreground: white;
--control-primary-background: blue;
--control-primary-border: 1px solid blue;
```

### Surfaces

```css
--surface-primary-foreground-color: var(--); 
--surface-primary-background-color: var(--); 
--surface-primary-border-color: var(--); 
--surface-secondary-foreground-color: var(--); 
--surface-secondary-background-color: var(--); 
--surface-secondary-border-color: var(--); 
--surface-auxiliary-foreground-color: var(--); 
--surface-auxiliary-background-color: var(--); 
--surface-auxiliary-border-color: var(--); 
```

### Typography

```css
--text-primary-font-family: "Inter Tight";
--text-primary-font-size: 32px;
--text-primary-font-weight: 400;
--text-primary-line-height: 1;
--text-secondary-font-family: Inter;
--text-secondary-font-size: 16px;
--text-secondary-font-weight: 400;
--text-secondary-line-height: 1.4;
--text-auxiliary-font-family: Inter;
--text-auxiliary-font-size: 12px;
--text-auxiliary-font-weight: 500;
--text-auxiliary-line-height: 1.2;
```
